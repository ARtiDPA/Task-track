# Структура приложения

```text
backend/app/
  main.py           # сборка приложения, CLI и жизненный цикл сервера
  api/http.py       # HTTP API, cookies, ответы и выдача фронтенда
  core/             # конфигурация, аутентификация, общая валидация
  persistence/      # SQLite, схема, транзакции и хранилище профилей
  services/         # правила финансов, привычек, фокуса, задач и других модулей
frontend/
  templates/        # HTML оболочка
  static/css/       # стили по модулям и визуальная тема
  static/js/        # клиентские модули и расчёты
scripts/            # восстановление и обслуживание
tests/              # API, бизнес-сценарии и браузерные проверки
data/               # рабочие данные и секреты, исключено из Git
```

Запуск: `docker compose up -d --build --wait` или `python -m backend.app.main` при установленном Python, зависимостях и доступном Redis.

Направление зависимостей: HTTP API → сервисы и хранилище → общие правила и настройки. `main.py` связывает сервер с хранилищем и аутентификацией. Сервисы получают соединение текущей транзакции, поэтому составные операции остаются атомарными. Статические файлы доступны только по явному списку разрешённых URL.

Структура следует разделению слоёв, привычному для FastAPI-проектов. HTTP-сервер сохранён на стандартной библиотеке Python; переход на FastAPI не требуется для изменения структуры. Существующие API URL и данные сохраняются.

## Проверки

```powershell
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
docker compose up -d --wait redis
python -m unittest discover -s tests -p "test_*.py" -v
python tests/browser_smoke.py
```

В Linux для браузерных зависимостей использовать `python -m playwright install --with-deps chromium`. Тесты создают временные базы и отдельные Redis-префиксы, не меняя рабочие профили.

## Визуальная тема

Базовые стили разделены по модулям. Финальный слой `frontend/static/css/nocturne.css` задаёт нейтральные графитовые поверхности и три роли цвета: `--accent-primary` (фиолетовый) — навигация и действия; `--accent-secondary` (ледяной голубой) — прогресс, вода и фокус; `--accent-tertiary` (янтарный) — серии, достижения и финансовые акценты. Текст и рамки остаются нейтральными. Цвета, выбранные пользователем для привычек, сохраняются.

`nocturne.js` отвечает только за декоративный canvas и настройку эффектов, берёт цвета матрицы из тех же CSS-переменных. Настройка хранится в браузере, учитывает `prefers-reduced-motion`; в скрытой вкладке отрисовка останавливается, частота ограничена примерно 15 кадрами в секунду.
