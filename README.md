# Ritmo — трекер привычек

Личный трекер на русском языке: привычки, ежедневные отметки, серии, статистика, годовая карта активности и достижения.

## Запуск

Из папки проекта запустите приложение (Python 3.10+, без внешних серверных зависимостей):

```powershell
python server.py
```

Затем откройте http://localhost:5173.

Сервер автоматически создаёт SQLite-базу `data/ritmo.sqlite3`. Прямое открытие `index.html` или `python -m http.server` больше не подходит: сохранение работает через API.

## Возможности

- Добавление, редактирование и удаление привычек с выбором цвета и значка.
- Отметки за текущую неделю; будущие дни и дни до создания привычки заблокированы.
- Текущие и лучшие серии, показатели за неделю и месяц, график выполнения.
- Карта активности за последние 365 дней с фильтром по привычке.
- Достижения за реальные результаты, анимации и конфетти за идеальный день.
- Адаптивная вёрстка, управление с клавиатуры, поддержка уменьшенного движения.
- Сохранение привычек, их даты создания, значков и цветов в SQLite.
- Сохранение статуса выполнения на каждую дату, включая отменённые отметки.
- Проценты учитывают только дни с момента создания каждой привычки.
- Автоматический перенос прежних данных из localStorage при первом подключении к пустой базе.

Начальные привычки — примеры, без выдуманных выполнений. При первом запуске откройте тот же адрес в том же браузере, где вели привычки: старая история перенесётся в базу автоматически. Существующая база никогда не перезаписывается старым кешем. Если у старой привычки нет даты создания, используется её самая ранняя отметка, а при отсутствии отметок — дата переноса.

База общая для браузеров на этом компьютере. Данные переживают перезапуск сервера и очистку браузера. Сервер слушает только локальный адрес, без аккаунтов и доступа из интернета. Каталог `data/` исключён из Git. Для резервного копирования остановите сервер и скопируйте каталог `data/`. Другой путь можно указать через `python server.py --database путь/к/базе.sqlite3`, другой порт — через `--port 5174`.

При ошибке сохранения интерфейс не применяет изменение и показывает сообщение; действие можно повторить. localStorage остаётся вспомогательной копией, источником данных служит SQLite. Шрифт Manrope загружается из Google Fonts; при отсутствии сети используется системный шрифт.

Проверка API, расчётов и пользовательских сценариев в Microsoft Edge. Все проверки используют временные базы и не меняют реальные данные:

```powershell
python -m pip install playwright
python -m unittest discover -s tests -p "test_*.py" -v
python tests/browser_smoke.py
```
