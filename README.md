# Ritmo — трекер привычек

Личный трекер на русском языке: привычки, ежедневные отметки, серии, статистика, годовая карта активности и достижения.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны.

Для локального сервера из папки проекта:

```powershell
python -m http.server 5173
```

Затем откройте http://localhost:5173.

## Возможности

- Добавление, редактирование и удаление привычек с выбором цвета и значка.
- Отметки за текущую неделю, включая прошедшие дни; будущие даты заблокированы.
- Текущие и лучшие серии, показатели за неделю и месяц, график выполнения.
- Карта активности за последние 365 дней с фильтром по привычке.
- Достижения за реальные результаты, анимации и конфетти за идеальный день.
- Адаптивная вёрстка, управление с клавиатуры, поддержка уменьшенного движения.
- Автоматическое сохранение в localStorage текущего браузера.

Начальные привычки — примеры, без выдуманных выполнений. Данные хранятся локально: синхронизации между устройствами нет. Для надёжного сохранения используйте один адрес и один браузер. Шрифт Manrope загружается из Google Fonts; при отсутствии сети используется системный шрифт. Других внешних зависимостей нет.
